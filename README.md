Програма моніторингу системних ресурсів

Опис

Репозиторій містить програму моніторингу системних ресурсів, яка призначена для моніторингу та керування системними ресурсами в операційній системі Windows. Програма надає інформацію в режимі реального часу про стан системи, зокрема завантаження процесора, використання оперативної пам’яті та список активних процесів.

Основною метою програми є допомога користувачам у відстеженні продуктивності системи та виявленні потенційних проблем, що можуть впливати на стабільність роботи операційної системи. Програма дозволяє аналізувати поведінку системи та виконувати базове керування запущеними процесами.

Фічі:

1. Моніторинг використання процесора в режимі реального часу
2. Моніторинг використання оперативної пам'яті в режимі реального часу
3. Відображення активних процесів
4. Можливість завершувати вибрані процеси
5. Можливість змінювати пріоритет процесів
6. Базовий аналіз продуктивності системи
7. Зручний інтерфейс для моніторингу даних
8. Виявлення високого використання ресурсів
9. Відображення детальної інформації про вибраний процес (ID, використання CPU та пам’яті)
10. Фільтрація або сортування списку процесів за використанням ресурсів
